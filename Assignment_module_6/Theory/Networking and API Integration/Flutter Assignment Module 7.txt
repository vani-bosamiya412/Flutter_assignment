1. Explain what a RESTful API is and its importance in mobile applications.
RESTful API (Representational State Transfer API) is a type of web service that allows applications to communicate over the internet using standard HTTP protocols.

Key points:
Stateless: Each request from a client (mobile app) contains all necessary information; the server doesn’t store client state.
Resource-based: Everything is treated as a resource (e.g., /users, /movies, /weather).
Uses standard HTTP methods: GET, POST, PUT, DELETE, etc.

Importance in mobile apps:
Fetch remote data: Apps can get live data like news, weather, or movies.
Send user input: Apps can submit forms, updates, or preferences to the server.
Platform-independent: A REST API can serve iOS, Android, or web apps with the same backend.
Scalable & maintainable: Easy to expand functionality without breaking existing apps.


2. Describe how JSON data is parsed and used in Flutter.
JSON (JavaScript Object Notation) is a lightweight format for exchanging data between server and client.
Steps in Flutter:
Fetch data from API: Use http.get() to call a REST API.
Decode JSON: Use dart:convert library.
Access data: The decoded JSON is usually a Map<String, dynamic> or List<dynamic>.
Use in UI: Pass the extracted values to Flutter widgets like Text, Image.network, or ListView.builder.


3. Explain the purpose of HTTP methods (GET, POST, PUT, DELETE) and when to use each.
HTTP 		Method					Purpose	Example Usage in Mobile Apps
GET		Retrieve data from the server		Fetch weather info, list of movies, news feed
POST		Send new data to the server		Submit login, signup, create a new post
PUT		Update existing data on the server	Update user profile, edit a saved note
DELETE		Remove data from the server		Delete a movie from favorites, remove an account
